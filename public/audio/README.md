# Music

Drop two files here:

| File             | Plays when             |
| ---------------- | ---------------------- |
| `day-theme.mp3`  | Day mode (headphones)  |
| `night-lofi.mp3` | Night mode (lantern)   |

If a file is missing, the site plays a built-in **original** synth track
(music-box waltz by day, lo-fi loop by night), so it never goes silent.

⚠️ Joe Hisaishi's "Merry-Go-Round of Life" (Howl's Moving Castle) is
copyrighted. Hosting/streaming it on a public site needs a licence (or use a
licensed cover / royalty-free piano waltz). This repo ships no copyrighted audio.
